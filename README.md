# 모아 — 매장 중개 프론트엔드 MVP

고객이 매장을 탐색하고 문의를 남기며, 운영자가 답변하는 흐름을 시연하는 React 앱입니다. 업종이 정해지지 않아 여러 종류의 동네 매장을 대상으로 구성했습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 배포용 빌드는 `npm run build`로 확인합니다.

## 화면과 데이터

- 고객: 매장 목록·검색·지역/카테고리 필터, 매장 상세, 문의 작성, 내 문의/답변 확인
- 운영자: 문의 목록·상태 필터, 문의 상세, 답변 및 상태 변경
- 매장 6곳과 샘플 문의 3건은 `src/data.ts`에 정의되어 있습니다.
- 새 문의와 답변 변경은 브라우저 `localStorage`에 저장됩니다. 같은 브라우저에서 새로고침 후에도 유지되지만 다른 기기와 공유되지 않습니다.

실제 로그인, 백엔드, 매장으로의 전송은 포함하지 않습니다. 상단의 **매장 운영자 화면** 링크로 역할을 전환해 전체 흐름을 시연할 수 있습니다.
